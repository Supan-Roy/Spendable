# Security Policy

## Supported Versions

We actively support security updates for the following versions of Spendable:

| Version | Supported |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

---

## Reporting a Vulnerability

We take the security of **Spendable** seriously. If you discover a security vulnerability, please **DO NOT** open a public GitHub issue.

Instead, please report security vulnerabilities directly via email:

📧 **contact@supanroy.com**

### What to Include in Your Report
- Type of vulnerability or issue (e.g. injection, data validation bypass, auth flaw)
- Step-by-step instructions to reproduce the vulnerability
- Any proof-of-concept scripts or payload examples
- Impact assessment of the issue

### Disclosure & Response Process
1. You will receive an acknowledgment email within **48 hours**.
2. We will investigate and confirm the report within **7 business days**.
3. A fix will be developed, tested, and released as quickly as practical.
4. We appreciate responsible disclosure and will credit researchers upon resolution.
